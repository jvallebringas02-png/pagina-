# remarket-db 🌱

**Portal de Economía Circular con Inteligencia Artificial**

Una plataforma web que conecta comercios y vecinos para fomentar la venta, el trueque y la donación de artículos, potenciada por un asistente de IA que personaliza la experiencia.

---

##  Características Principales

- 🤖 **Asistente IA Corporativo**: Responde en 1-3 oraciones, conoce al usuario y redirige temas fuera de contexto.
-  **16 Idiomas**: Incluye Quechua y Aymara para inclusión cultural.
-  **Publicaciones**: Venta 💰, Trueque 🔄 y Donación 🎁.
-  **Buscador Inteligente (Fase 2)**: Filtra por texto, categoría, ubicación y modalidad.
- 📱 **Códigos QR**: Genera y descarga QR para cada publicación.
- 🔒 **Seguridad**: Declaración Jurada obligatoria para publicar y usar el chat IA.
- 🎨 **Diseño Responsive**: Adaptado a móviles, tablets y desktop.
